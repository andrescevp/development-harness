# software-engineer: tdd-caught-contract-mismatches

## Context
Vitest TDD caught real contract mismatches before shipping: TS strict noUncheckedIndexedAccess array indexing, folded greater-than YAML descriptions not containing the literal skill name, and the frontmatter splitter keeping a leading newline in the body. Naive assumptions about builder and frontmatter semantics failed against the actual implementation.

## Outcome
Tests were rewritten to assert against the real builder and frontmatter semantics; 51 tests pass out of 51. Lesson: tests must encode actual semantics of the code under test, not assumed ones.

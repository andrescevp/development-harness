# software-architect: normalized-agent-names-for-scoped-bundle

## Context
A scoped plugin registers fewer agents than the source harness references: @build, @senior-engineer, @senior-architect, and @plan do not resolve at runtime, only the 6 manifest agents do. Delegation references in bundled skills were patched to the software-* names, an AGENTS.md normalization mapping table was published, and the audit treats out-of-bundle mentions such as @build as warn-only external-harness references.

## Outcome
Loop-critical patched sections carry no unresolved @build or @senior-* reliance; 8 at-mentions and 72 prose tokens are documented warn-only and the audit still exits 0.

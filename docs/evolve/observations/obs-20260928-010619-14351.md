# reviewer: hardened-extraction-symlink-secrets

## Context
Review findings on the extractor: .env* was missing from the junk exclusion list, symlinks were dereferenced without a guard, and --check did not enforce zero symlinks. Fixes: exclude .env* in the junk matcher BEFORE the directory early-return, dereference symlinks only inside SOURCE_ROOT via a realpath guard, and probe both behaviors with temporary fixtures during validation.

## Outcome
Probe tests verify .env* is skipped, CHECK fails on a symlink then passes after removal, 0 symlinks in the destination tree, and extract --check is idempotent with a clean byte-compare.

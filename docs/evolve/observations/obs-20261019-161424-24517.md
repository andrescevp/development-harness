# dh-software-architect: migrated-plugin-tools-to-project-scope-mcp-server

## Context
The dev-harness plugin registered 7 tools via the opencode plugin tool API. The plan migrated them to a project-scope local MCP stdio server (`@modelcontextprotocol/server` v2), removed plugin tool registration (hard cut), flipped naming to `dh_<tool>` / `tools.dh.<tool>`, and wired projects via `mcp.servers.dh` (npx from git). Evidence: `docs/plans/plugin-tools-to-mcp/tasks/{verification.md,review.md,release.md}`.

## Durable learnings

- **Hard-cut migrations need removal proof:** throwing domain stubs + `toolTouches` counter + guard meta-tests + a static assertion that the built bundle contains no tool strings/`duckdb`. Asserting the new path alone does not prove the old one is gone.
- **MCP stdio specifics:** compare `realpathSync(argv[1])` with `realpathSync(fileURLToPath(import.meta.url))` for the main guard — npm/npx `.bin` entries are symlinks and a naive URL compare silently no-ops. stdout is the protocol channel (stderr-only logging); `serveStdio` serves legacy 2025-era clients by default; server `instructions` are constructor-only (`McpServer(info, { instructions })`, read via `client.getInstructions()`).
- **Write-path hardening that held up:** same-dir temp created with `flag:'wx'` (blocks pre-planted temp symlinks) + `renameSync` (overwrite, mode preserved from `statSync`) / `linkSync` (exclusive create, EEXIST) + `O_NOFOLLOW` fd reads and index append; treat `ENOTDIR` as stop-traversal so legacy messages survive; never `await` inside plan read-modify-write.
- **Packaging:** a `dist/.build-ok` sentinel written by the last build step beats existence-only prepare skips (partial builds mask as complete); guard `require.resolve('tsup')` for `--omit=dev` installs; deep-importing a single symbol (`@opencode/plugin/promise/plugin` `define`) instead of the package barrel cut the plugin bundle ~79% (978 KB → 208 KB); `npx --package=github:…` resolves the REMOTE default branch — verify pre-release with `git+file:<repo>` (cold 24 s: clone → install → prepare → handshake).
- **Docs/config surfaces:** keep snippet copies field-verified across every doc surface (README, LOADING, example, skill, demo); field comparison (not whole-file diff) for inline forms; ship `timeout.startup` actively once a cold path is measured near the host default.
- **Process:** docs-only sub-tasks can use a single consolidated three-lens pass (recorded deviation); long-lived `opencode serve` keeps previously spawned MCP children alive — restart before trusting `mcp list` after rebuilds; a stale-dist gate order (`test` before `build`) can false-pass — build before test.

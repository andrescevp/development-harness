# software-engineer: discovered-pnpm-audit-name-collision

## Context
A package.json npm script named audit (the harness manifest audit) collides with pnpm built-in dependency security audit. Bare pnpm audit runs the security tool (reports a low dev-only esbuild advisory and exits 1) instead of the harness audit; docs and gates that say pnpm audit silently run the wrong tool.

## Outcome
Custom script must be invoked as pnpm run audit; the loading guide now documents the distinction, and the release gate uses pnpm run audit.

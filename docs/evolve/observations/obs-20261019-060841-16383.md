# dh-reviewer: normalized-doc-tool-refs-to-registered-dot-ids

## Context
Docs, skills and agents referenced plugin tools by underscore spellings (dh_plan_read, dh_logged_command) while the plugin registers namespace dh with runtime IDs dh.plan_read, dh.logged_command. 40 refs across 13 files were normalized; the reviewer verified occurrence-count conservation via a token-normalized diff (rename-only).

## Outcome
Zero underscore refs remain on the active surface (zero-match grep gate); out-of-brief stragglers found by sweep (dh-setup:37 fixed, src/ header comments recorded as follow-up). Lesson: documentation must reference the runtime tool ID (namespace.name); verify renames with a zero-match grep on the old spelling.
